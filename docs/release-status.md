# Windows 试用版状态

版本 v1.17.24，Windows x64 试用版，程序未数字签名。

应用名称为 SandUp · 沙立，启动文件为 `SandUp.exe`。用户数据沿用旧版目录。发布版自带 .NET 10.0.15 和 SQLite 3.54.1，说明文档和第三方依赖声明可在同一目录查看。

悬浮沙漏窗口缩至 104 × 104 个逻辑像素。悬停倒计时用带淡阴影的数字显示，玻璃轮廓连续可见。

主页在后台自动保存计时记录，保存异常时显示提示和重试入口。

悬浮沙漏交叉处使用一条连续轮廓，上下腔室大小相同。玻璃反光跟随固定的左上方光源，翻转时沿两斗曲面移动，亮度随角度变化。

主页「耐久度」左侧的小人沿用悬浮沙漏的玻璃轮廓和金色沙堆，玻璃反光较淡。小人用白色竖眼、短手套和短靴，双臂从沙面高度接出。系统允许动画时，主页小人约每五秒眨一次眼。鼠标移到脸上会立刻眨眼，移到手上时对应的手会挥一次。六条虚线从对应部位附近接出，在聚焦或悬停部位时高亮对应项。

默认窗口为 640 × 580。主页分开显示今日工作、今日休息，并用蓝绿模块展示计划进度。肩颈图标使用颈部和双肩轮廓，部位命名为「腹部」。

主页、设置、统计、全屏休息、应用弹窗和托盘菜单采用暗色主题。计划和统计统一用蓝色表示工作，绿色表示休息。悬浮沙漏有白色细轮廓、上下玻璃高光和金色沙粒。

应用自绘窗口及弹出资料卡使用 Noto Sans SC，字体随程序离线加载。发布目录含 Noto Sans SC 原版版权声明和 SIL OFL 1.1。

六张部位资料卡统一按“休息方式”“久坐伏案”“依据”的顺序显示。

设置的组合库按“组合1”“组合2”等命名，点击在名称下展开。新建时内容为空。每处引用有独立的重复次数，旧组合的次数迁入对应引用。右侧竖排显示“完整计划预览”。新计划默认开启“合并连续模块”，相邻的同类模块按总时长显示和计时。

「计划安排」下方的「保存为组合」将当前编排收入组合库。点击「保存设置」后写入本地记录。

设置标题显示保存状态。未保存的编排或扣分参数会在切页、关闭窗口和托盘退出前要求确认。计划安排有与组合库、预览一致的边框，「合并连续模块」位于「保存为组合」下方。

计划模块和添加按钮集中在「计划安排」标题下的内框，「保存为组合」位于内框下方。

从当前版本建立v1.0.0基线（用户指定的第一版），源码和文档由本地Git管理。日常程序固定放在output/release/current，更新前需先退出程序；不再自动创建时间戳目录，也不生成ZIP。版本编号不代表尚未执行的实机验收已通过。

已实现计时核心、离线记录、休息窗口、历史活动补填、日期查询、草稿保存与导出。

六项耐久度的回归测试覆盖旧设置、历史缺日与补填、自定义扣分速度、跨午夜、全屏勾选和窗口宽度变化。

悬浮沙漏默认显示且可拖动。工作剩余 20 秒时站起，单手挥动并定时眨眼。剩余 10 秒双手挥动，预警弹窗避开浮标位置；最后 2 秒变回沙漏。进入全屏休息时隐藏浮标。设置页和托盘可切换显示，位置与开关保存在 desktop.json。暂停时停止流沙和互动动画。休息屏的小人按当前提示示范远眺、轻抬双手或交替迈步。

悬浮窗为透明背景，显示白色轮廓和金色流沙。待开始时沙在下方，新轮翻转时沙面保持水平并滑动，接近直立时细沙逐渐从颈口落下、积成沙堆。倒计时仅悬停时显示在沙漏内部。

休息计时阶段可以换提示或应急退出。到点停在原全屏窗显示“休息完成”，选择开始下一轮、稍后继续或按Esc后回到桌面。等待选择期间不再计时。

主页六行分别展示眼睛、肩颈、腰背、腹部、臀腿、肛门·前列腺的今日和历史耐久度。历史在本地午夜按部位结算，保留上次历史的 80%，纳入刚结束的有效日实际日末分的 20%。今天从 100 分重新开始。臀腿图标为侧面迈步的下半身。指向任意部位图标或名称即可阅读本地资料卡，卡片含相关问题、动作和出处。设置页可改每项每小时的扣分，随附《耐久度研究依据.md》说明研究能回答的问题及卡片动作的来源。

“记录”打开统计看板，顶部默认展示今天的工作、休息、完成轮次和每轮平均时长。点击柱子或用日历选择日期，顶部概览和当日明细一起更新。下方趋势可切换7天和30天。已结束轮次可以补填活动，页面底部提供刷新、导出和清空。

主页将计时与操作并排，显示今日累计。身体简笔画在左侧用虚线连到六项耐久度，肩颈图标重绘。工作备忘录位于 10 秒预警和全屏休息。预警输入框选中后可在 00:00 继续输入，按「开始休息」保存；全屏编辑会暂停休息，按「确定」后继续。额外编辑时间计为工作。

应用内按钮为线条图案，提供悬停提示与可访问名称。程序、窗口和托盘统一使用主页的沙漏小人图标，配深色圆角底和透明外角。Windows 图标包含 16 至 256 像素共七种尺寸。

未完成验收：真实双屏/混合缩放、睡眠唤醒及远程会话、完整键盘操作、长时间资源占用、全新Windows环境。不得把自动测试通过等同于这些项目通过。

若系统安全功能阻止运行，请不要为此关闭系统安全防护；保留提示供后续签名与发布验证。

设置页可为当前 Windows 用户开启「开机自启动」，默认关闭。登录时从托盘启动，手动开始计时。卸载时可先关闭开机自启动，再删除解压目录。个人记录单独位于 LocalAppData。
