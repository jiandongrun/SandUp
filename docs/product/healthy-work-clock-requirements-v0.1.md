# 健康工作钟 · 一页需求说明

v0.1 草案 | Windows 桌面端 | 2026-10-25

**产品目标**：帮助长时间使用电脑学习、工作的人定时离屏活动，并顺利回到原任务。轻量、离线、本地保存，以温和提醒和自主选择为原则。

**核心流程**：开始工作 → 休息预告 → 收尾或短暂延后 → 全屏休息 → 自愿记录活动 → 查看接续事项 → 手动开始下一轮。

## 使用规则

| 环节 | 第一版行为 |
| --- | --- |
| 工作计时 | 默认工作 25 分钟、休息 5 分钟，可修改。支持暂停、继续；保留本轮累计工作时间。关闭主窗口后留在托盘；“退出应用”才停止运行。 |
| 休息预告 | 到点前 30 秒显示轻提示，可填写“回来接着做什么”。输入自动保存，内容可留空；到点自动进入休息屏。 |
| 自然延后 | 预告和休息屏均可选延后 3 / 5 分钟；休息屏仅在本次尚未延后时提供。每轮最多一次，可提前结束延后并休息。延后期间继续累计工作时间，提醒先保存工作、收尾。 |
| 全屏休息 | 到点覆盖各显示器，显示剩余休息时间和少量离屏活动提示，如看向远处、起身走动、轻松活动肩手。提示可切换，无强制任务、无视频依赖。 |
| 紧急处理 | 预告、延后和休息屏均可“一键应急退出”；休息屏也支持 Esc。立即移除遮罩，无二次确认、无惩罚；记录本轮休息跳过或提前结束，停止计时，用户手动恢复。 |
| 记录与返回 | 休息计时结束即退出全屏，显示非阻挡确认页；活动默认不勾选，支持多选和“不记录，继续”。未填记为“未记录”；勾选只是自报，不推断真实运动完成。显示接续事项，手动启动下一轮。 |
| 中断与异常 | 手动暂停、锁屏、系统睡眠均不累计工作；解锁或唤醒后等待手动继续。退出或崩溃后保留已有记录和草稿，重新打开不自动弹休息屏。 |

**默认参数说明**：25 / 5 分钟、提前 30 秒、延后 3 / 5 分钟和每轮一次延后，均为待试用验证的产品默认值，不是医学建议。

## 数据、范围与验收

**本地记录**：保存日期、本轮实际计时、延后时长、休息屏计时、结束原因、自报活动和可选接续事项；休息屏时长不等于真实运动时长。支持查看、导出、清空；清空需确认。无账号、无云同步、无广告，不采集屏幕或其他应用的输入内容。

**第一版统计**：展示工作计时、休息计时、计时完成 / 跳过 / 提前结束次数和自报活动。暂不推出“健康工作指数”；后续若引入，应公开算法并标注为习惯参考，不能评价身体健康。

**暂缓范围**：账号同步、社交排行、AI 动作识别、复杂任务管理、自动保存其他软件内容。接续事项只保存用户写入本应用的文字。

**验收底线**：① 正常一轮能走通并落盘；② 延后后累计时间正确、草稿不丢；③ 任何休息屏可立即退出且不马上重弹；④ 锁屏 / 睡眠不算工作；⑤ 不勾选也能继续且不虚报完成；⑥ 重启仍可查看记录、导出和清空。
